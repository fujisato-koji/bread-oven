# 2. 構造様式

型式を比べて選び、層の構成、基礎、台、屋根の形を決める。
寸法と熱の計算は [3. 構造設計](03-structural-design.md) で行う。
出典の記号（P、S、M、F）は[出典](sources.md)の番号。

## 2.5 選定案

H（レンガ内張りの土窯）を第一案にする。
施主の確認を待つ。

選ぶ理由は次のとおり。

1. 生地に触れる炉床と、熱を放つ内面を耐火レンガにすれば、R-02d の底の焦げにくさが得られる（P7）。
2. 蓄熱は、焚いている間に熱が届く深さまでしか働かない。熱の届く深さは $L \approx \sqrt{\alpha t}$ で、耐火レンガ（$\alpha = 4.0 \times 10^{-7}$ m²/s）では 1.5 時間で 4.6 cm、3 時間で 6.6 cm、6 時間で 9.3 cm（P7 の式と物性から計算）。レンガ 65 mm と土 60 mm を合わせた 12.5 cm は、6 時間焚いても余る厚さなので、B のようにレンガを 114 mm 積む必要は薄い。
3. 蓄熱の外側を土にすると、レンガの数が B の約 3 分の 2 になる（2.3）。

ほかの案を選び直す条件は次のとおり。

| 条件 | 選び直す案 |
|------|-----------|
| 分解して運ぶ移設が要る | D（部材に分けて鋳込む） |
| 移設は要らず、敷地で粘土が採れ、もっと安くしたい | A |

## 2.6 H の層の構成（案）

下から順に並べる。
厚さは仮で、[構造設計](03-structural-design.md)で決める。

| 層 | 材料 | 厚さ（仮） | 働き | 根拠 |
|----|------|-----------|------|------|
| 基礎 | 砕石と鉄筋コンクリート | 未定 | 凍上を受け流す | P19a、F13、P28 |
| 台 | コンクリートブロック | 高さ 0.85 m | 炉床を腰の高さに置く。下を薪置きにする | 仮定 |
| 床版 | 鉄筋コンクリート | 100 mm | 窯の重さを台へ渡す | 仮定 |
| 炉床の断熱 | パーライトとセメント（1:5） | 100 mm | 炉床の熱を下へ逃がさない。乾燥密度 350 kg/m³、熱伝導率 0.08 W/(m K) | P25 |
| 炉床 | 耐火粘土レンガの平置き | 65 mm | 生地の底を焼く（R-02d） | P7 |
| 窯壁 | 耐火粘土レンガ、耐火モルタルの目地 | 65 mm | 内面から熱を放つ | P7 |
| 蓄熱層 | 粘土と砂 | 60 mm | 熱をためる | P7、S9 |
| 断熱 | パーライトとセメント（1:5） | 100 mm | 熱を逃がさない。外面を熱くしない（R-12） | P25、S2 |
| 外殻 | 左官の仕上げ | 30 mm | 雨から断熱を守る | F14 |
| 前室と焚き口 | 耐火粘土レンガ | | 扉で焼き室を閉じ、煙突は扉の外に出す（R-02c） | S2 |
| 煙突 | 金属の煙突、ダンパー付き | | 屋根面から 60 cm 以上出す | P26 |
| 屋根 | 未定 | | 断熱と外殻を雨と雪から守る（R-08） | F6、F14 |

焚き口の高さは、内高の 55% から 60% を目安にする。
実在の窯の比は 55%（P5）、60%（P13）、約 60%（F2）だった（計算）。
よく言われる 63% は、ケベックの古い窯の寸法の統計で、性能を比べた資料は見つからなかった（F1）。
焚き口の幅は直径の半分以下にする（S10、二次）。

## 2.7 基礎、台、屋根の様式（候補）

| 部位 | 候補 | 移設 | 凍上 | 費用 |
|------|------|------|------|------|
| 基礎 | 凍結深度より深い基礎 | 向かない | 確実 | 掘削とコンクリートが多い |
| 基礎 | 砕石の上に浮かせたスラブ（F13） | 床版ごと持ち上げられる | 排水が要。動いても壊れない作りにする | 安い |
| 基礎 | 断熱を下に敷く浅い基礎（FPSF、P28） | 向かない | 確実 | 断熱材がかかる |
| 台 | ブロックを積んでモルタルで固める | 向かない | | 安い |
| 台 | ブロックを乾式で積む | 積み直せる | | 安い |
| 台 | 鋼の枠 | 丸ごと動かせる | | 高い |
| 屋根 | 柱と屋根の窯小屋 | 小屋は別に移す | | 建築物になる（1.5）。費用が大きい |
| 屋根 | 窯に防水の外殻だけ付ける | 窯と一緒に動く | | 安い。冬の使い勝手は劣る |

移設の範囲（[要求](01-requirements.md) 1.4 の 7）が決まってから選ぶ。
