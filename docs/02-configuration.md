# 2. 構造様式

型式を比べて選び、層の構成、基礎、屋根の形を決める。
寸法と熱の計算は [3. 構造設計](03-structural-design.md) で行う。

## 2.1 比べる候補

| 記号 | 型式 | 中身 |
|------|------|------|
| A | 土窯 | 粘土と砂でドームを一体に固める。炉床だけ耐火レンガ |
| B | 耐火レンガのドーム | 耐火レンガを半球に積む |
| C | 耐火レンガのバレル | 耐火レンガでかまぼこ形の天井を積み、外に蓄熱層を厚く付ける |
| D | 鋳込みの部材 | 自作の型に耐火キャスタブルを流し、部材にして組む |
| E | 焚き室を分ける窯 | 薪を焚く室と焼く室を分け、焼きながら焚ける |
| F | 市販のキットや完成品 | 鋳込みのドームや金属製の窯を買って据える |

ガスや電気の窯は、燃料を薪とする R-06 から外す。

## 2.2 比べる物差し

| 物差し | 引く要求 | 見る所 |
|--------|---------|--------|
| 焼きの出来 | R-02 | 蓄熱の量、天井の高さ、扉の密閉、炉床の材料 |
| ピザ | R-03 | 炎を残した高温、天井の低さ |
| 量 | R-04 | 炉床の広さ、余熱で何回窯入れできるか |
| 傷みにくさ | R-05、R-08 | 吸湿と凍結融解への強さ、雨への強さ |
| 自分で組めるか | R-07 | 重い部材、特殊な道具の要否 |
| 費用 | R-09、R-10 | 材料費の見当 |
| 移設 | R-13 | 丸ごと動かせるか、分解して組み直せるか |
