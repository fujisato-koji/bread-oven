# 1. 要求

窯が満たすべきことを番号付きで並べる。
後の段（構造様式、構造設計、部品リスト）は、この番号を引いて理由を示す。

## 1.1 前提

2026-10-17 に施主（自分）が決めたこと。

| 項目 | 決めたこと |
|------|-----------|
| 焼くもの | ハード系のパンの直焼き、ピザ |
| 出来 | 一流のパンが焼けること |
| 量と頻度 | たまに大量に焼く（1 回に 12 個より多く、年に数回） |
| 作り方 | 自分で組む |
| 据える所 | 自宅の庭。屋外に据えて冬も使う |
| 燃料 | 薪。薪は十分にある |
| 費用 | 10 万円以下。できるだけ安く。超えそうなら知らせる |
| 移設 | できれば移設できるようにする |

## 1.2 要求の一覧

由来の欄の「施主」は 1.1 の決めごと、「導出」は施主の決めごとから引き出したもの。
導出の要求は施主の確認を待つ。
R-13 だけは「できれば」の要求で、ほかの要求とぶつかったら、ほかの要求を先に満たす。

| 番号 | 要求 | 由来 | 設計点（合否の物差し） | 状態 |
|------|------|------|----------------------|------|
| R-01 | ハード系のパンを、炉床に直に置いて焼ける | 施主 | 炉床に置いて焼く。天板や型を使わない | 確定 |
| R-02 | 一流のパンが焼ける | 施主 | R-02a から R-02e に分けて測る | 確定 |
| R-02a | 窯入れのときの炉床の温度が、ハード系に足りる | 導出 | 炉床の表面温度の範囲（文献待ち） | 文献待ち |
| R-02b | 焼いている間の温度の下がり方が緩やか | 導出 | 1 回の焼成の間の温度低下の上限（文献待ち） | 文献待ち |
| R-02c | 焼き始めに蒸気を閉じ込められる | 導出 | 扉で焚き口をふさぎ、煙突を閉じられる | 文献待ち |
| R-02d | 底が焦げず、上もよく色づく | 導出 | 炉床と天井の温度の差の範囲（文献待ち） | 文献待ち |
| R-02e | 炉床の場所による焼きむらが小さい | 導出 | 炉床の温度むらの上限（文献待ち） | 文献待ち |
| R-03 | ピザも焼ける | 施主 | 炎を残したまま、炉床の表面を高温にできる（値は文献待ち） | 文献待ち |
| R-04 | 1 回に 12 個より多く焼ける | 施主 | 1 回の焼成日で焼き切る個数。1 個の大きさは未定 | 未確定 |
| R-05 | 年に数回の使用で傷まない | 施主 | 使わない間の吸湿と凍結で割れない。使う前の乾燥の手順を持つ | 文献待ち |
| R-06 | 燃料は薪 | 施主 | 薪だけで R-02 と R-03 を満たす。薪の量は制約にしない | 確定 |
| R-07 | 自分で組める | 施主 | 個人が手で運べる部材と、手に入る道具で組める | 導出、確認待ち |
| R-08 | 屋外に据えて冬も使える | 施主 | 雨と雪で断熱が濡れない。凍結融解と凍上で壊れない | 文献待ち |
| R-09 | 費用は 10 万円以下 | 施主 | 部品リストの合計が 10 万円以下。超えそうなら知らせる | 確定 |
| R-10 | できるだけ安い | 施主 | R-01 から R-08 を満たす案のうち、合計が最も安い案を選ぶ | 確定 |
| R-11 | 法令に適う | 導出 | 火災予防条例、建築基準法、廃棄物処理法に当たるかを確かめ、当たれば満たす | 文献待ち |
| R-12 | 使う人がやけどせず、火の粉で燃え広がらない | 導出 | 外面の温度、薪置きと燃えやすい物の離隔（文献待ち） | 文献待ち |
| R-13 | できれば移設できる | 施主 | 移設の範囲（1.4 の 7）が決まってから設計点にする | 未確定 |

## 1.3 要求どうしのぶつかり

| ぶつかり | 中身 | 折り合いの付け所 |
|----------|------|----------------|
| R-02、R-04 と R-09、R-10 | 炉床を広くし、蓄熱を厚くすると材料が増える | 材料の単価を下げる（土や中古のレンガ）か、炉床の広さを 1 回の窯入れでなく余熱での複数回で稼ぐ |
| R-01、R-02c と R-03 | パンは炎を掻き出して扉を閉めて焼き、ピザは炎を残して焼く | 天井の高さと焚き口の高さ、扉の作りで両立させる |
| R-08 と R-09 | 屋外で冬も使うには屋根か防水の外殻が要り、費用がかかる | 屋根を窯の費用に含めるかを施主が決める（1.4 の 3） |
| R-13 と R-10 | 安い土窯は一体に固めるので、動かすと割れる。動かせる作りは台や枠の費用がかかる | 移設の範囲（1.4 の 7）で決める。分解して組み直すなら、乾式の積み方にする |
| R-13 と R-08 | 地面に固定しない台は、凍上や強風への備えが別に要る | 構造様式で基礎の形を比べる |
