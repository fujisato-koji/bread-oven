# 3D の全体像

窯の全体を three.js で描いた図。
寸法はすべて [oven.json](data/oven.json) から読むので、設計が進んで値が変わると図も変わる。

!!! warning "いまの寸法は仮置き"
    第一案は分割のキャスタブルのドーム（内径 0.6 m、内高 0.30 m、4 個、[構造様式](02-configuration.md) 2.5）である。
    台は、ボルトで組む 3 本脚（後ろの脚を ±0.90 m に張り出す、[構造設計](03-structural-design.md) 3.5）で描く。
    寸法は文献から置いた仮の値で、構造設計で決める。
    図は、部品の並びと大きさの見当をつけるためのもの。
    値の状態（仮、決定、未定）と根拠は、図の左の表に出る。

## 使い方

- ドラッグで回し、ホイールで寄り引きし、右ドラッグで動かす。
- 左の「型式」で、分割のキャスタブルのドーム（第一案）と、レンガのドーム（前の第一案、参考）を切り替える。
- 「中心で切って断面を見る」で、ドームの 4 個と継ぎ目、四角の炉床、毛布、殻の重なりが見える。
    切った面は中身を塗って描く。
- 「殻を透かす」で、殻の中のドームと毛布が見える。
- 「地面を透かして据え台を見る」で、据え台の下の締めた砕石と凍結深度の面と、埋めた風の留めの平板と全ねじが見える。
- 「空気の流れ」で場面（焚く、焼く、温度を下げる、殻の換気）を選ぶと、空気と煙と湯気の流れを、曲線に沿って動く矢印と粒で描く。
    冷たい空気は青、火で温まった煙は赤から橙、H 笠から出る煙は灰茶、前室の口の上からこぼれる煙は淡い灰茶、焼き室の熱い空気は橙、湯気は白、差し込みの扉のまわりの漏れは細い淡い橙、殻の中の湿気を連れた空気は青緑で描き、図の左上に凡例が出る。
    場面を選ぶと、差し込みの扉の位置と垂れ壁も場面に合わせて描く（焚くときは扉を外して垂れ壁を掛け、焼くときは扉で閉じ、温度を下げるときは扉を抜いて立てる）。
    「差し込みの扉の位置」で、閉じる、緩める（面の板と枠のすきま 10 mm）、抜く（毛布の面と枠のすきま 25 mm）、外すを選べ、「前室の口に垂れ壁を掛ける」で垂れ壁を付け外しできる。
    焚く場面で垂れ壁を外すと、前室の口の上からこぼれる流れが増える。
    殻の換気を選ぶと殻を透かし、ほかの場面へ移ると元に戻す。
    壁の向こうの流れは薄く透かして描く。
    断面では透かさずに切り口より奥の流れを描くので、焼き室の中の流れがはっきり見える。
    曲線は oven.json の寸法から作る。
    焚く、焼く、温度を下げるの流れの道は構造設計 3.2.8 と 3.9.7 の計算に合わせた絵で、矢印の本数と速さは量を比べる目安である（計算、推定）。
    殻の換気の流れは説明のための絵で、測っても計算してもいない（推定）。
- 部品をクリックすると、材料と寸法が左に出る。
- 左の「部品」の印で部品ごとに表示と非表示を切り替え、「全部表示」と「全部隠す」でまとめて切り替えられる（隠した部品は押しても選ばれない）。

URL の後ろに条件を付けると、その状態で開く。

| 例 | 開く状態 |
|----|----------|
| `viewer/?type=brick` | レンガのドーム（前の第一案） |
| `viewer/?section=1` | 断面を側面から |
| `viewer/?view=top` | 上から |
| `viewer/?flow=fire` | 焚くときの空気と煙の流れ |
| `viewer/?flow=bake&section=1` | 焼くときの焼き室の中の流れと湯気を断面で |
| `viewer/?flow=fire&lip=0` | 垂れ壁を外して焚くときの流れ（`lip` を省くと垂れ壁を掛ける） |
| `viewer/?flow=cool&door=loose` | 差し込みの扉を緩めて温度を下げるときの流れ（`door` を省くと抜いた段、`door=off` で外した段） |
| `viewer/?flow=shell` | 殻の換気（殻を透かして開く） |
| `viewer/?hide=shell,insulation` | 殻と毛布を隠して開く（左の欄で切り替えると URL の `hide` も替わる） |
