# 3D の全体像

窯の全体を three.js で描いた図。
寸法はすべて [oven.json](data/oven.json) から読むので、設計が進んで値が変わると図も変わる。

!!! warning "いまの寸法は仮置き"
    第一案は耐火レンガのドーム（内径 0.8 m、[構造様式](02-configuration.md) 2.5）である。
    寸法は文献から置いた仮の値で、構造設計で決める。
    図は、部品の並びと大きさの見当をつけるためのもの。
    値の状態（仮、決定、未定）と根拠は、図の左の表に出る。

[図を全画面で開く](viewer/index.html){ target="_blank" }

## 使い方

- ドラッグで回し、ホイールで寄り引きし、右ドラッグで動かす。
- 左の「型式」で、レンガのドーム（第一案）、土窯、バレル（費用で外した型式、参考）を切り替える。
- 「中心で切って断面を見る」で、窯壁、断熱、外殻の重なりが見える。切った面は中身を塗って描く。
- 「地面を透かして基礎を見る」で、地面の下の基礎が見える。凍結深度が決まると、その面も出る。
- 部品をクリックすると、材料と寸法が左に出る。

URL の後ろに条件を付けると、その状態で開く。

| 例 | 開く状態 |
|----|----------|
| `viewer/?type=earth` | 土窯 |
| `viewer/?section=1` | 断面を側面から |
| `viewer/?view=top` | 上から |
