# 4. 部材の入手性

構造設計で決めた部材を、個人が手に入れられるかを確かめる。
手に入らない、高すぎる、運べない部材が出たら、理由と戻し先をこの文書の表に書いてから、構造様式か構造設計を直す。

## 4.1 入手性の確かめ方

| 見る所 | 中身 |
|--------|------|
| 買える所 | ホームセンター、通販、窯業の問屋、解体材 |
| 単価 | 買える所の値段。URL と取得日を残す |
| 量の単位 | ばらで買えるか、袋や箱でしか買えないか |
| 運べるか | 1 個の重さ、自家用車に載るか、送料 |
| 代わり | 同じ働きをする安い物、中古、敷地で採れる物 |
