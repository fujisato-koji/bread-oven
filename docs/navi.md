# ナビゲータ

設計の中身を、5 つのモードで切り替えて見るための画面である。
全画面で開いて使う。

[ナビゲータを開く](navigator/index.html){ .md-button .md-button--primary target="_blank" }

| モード | 見るもの |
|--------|---------|
| 要求 | 要求の木と、要求を満たす部品と工程の対応表 |
| フロー | 焚き方と焼き方の流れ（窯と生地の 2 つのレーン） |
| 系統図 | 焼いている間の熱の流れ、焚く間の熱と煙、蒸気の通り道 |
| 図面 | 平面図、正面図、断面図。寸法は oven.json から描く |
| 3D | 3D の図。選んだ部品が光る |

どのモードでも、部品（炉床、扉など）を選ぶと、ほかのモードでも同じ部品が選ばれる。
右の札に、選んだものの中身と、ほかのモードへの行き先が出る。

ナビゲータのデータは、要求の表（[要求](01-requirements.md)の 1.2）、`docs/data/model.yaml`、`docs/data/oven.json`、[出典](sources.md)の表から作る。
作り方と決まりごとは、リポジトリの `NAVIGATOR.md` に書いてある。
