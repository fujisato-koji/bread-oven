# 3. 構造設計

型式が決まってから、寸法と熱と構造を計算する。
設計点（合否の値）と期待値（うまくいけば届く値）を分けて表にする。

## 3.1 これから計算すること

| 項目 | 引く要求 | 中身 |
|------|---------|------|
| 炉床の広さ | R-04 | 1 個の生地の大きさと間隔から、1 回の窯入れの個数を出す |
| 天井の高さと焚き口 | R-02d、R-03 | 内高、焚き口の高さと幅 |
| 蓄熱 | R-02b、R-04 | 蓄熱体の熱容量と、余熱で焼ける回数 |
| 断熱 | R-02b、R-12 | 外面の温度と、熱の逃げ |
| 昇温 | R-02a、R-03 | 炉床が窯入れの温度に届くまでの時間と薪の量 |
| 基礎と台 | R-08、R-13 | 重さ、凍上への備え、動かし方 |
| 屋根 | R-08、R-11 | 雪の重さ、煙突との離れ |

寸法の値は [oven.json](data/oven.json) に置く。
